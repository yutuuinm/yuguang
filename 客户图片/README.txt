客户图片库 · 使用说明
======================

本目录（site/客户图片/ → 部署后为 客户图片/）即予光的客户图片库（等同白桦 Remy 库的角色），存放「客户图片」：
买家秀 / 佩戴照 / 定制素材 / 客户提供的设计参考图等。

命名建议（方便按客户/订单管理）：
  customer-订单号-序号.jpg    例：customer-20240901-1.jpg
  （或用 客户名/昵称 拼音 + 序号）

使用方式：
1. 图片放入本目录，首页「微光时刻」与后续客户作品栏目即可引用；
2. 引用路径统一写：客户图片/文件名.jpg
3. 已放入示例：示例图片.jpg —— 首页第一条微光时刻已展示它（占位图会自动被替换）；
4. 单文件版（予光完整版.html）重新打包时会自动内联本目录已有图片；
5. 部署到 GitHub 时，./_deploy.sh 会自动带上整个目录；
6. 将来接入 Supabase Storage 后，可把图片上传至名为 customer-images 的桶，
   本目录仍作为本地素材库与展示层保留。

提示：为保障加载速度，单张建议 ≤ 1MB、长边 ≤ 2000px。
