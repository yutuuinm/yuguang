📋 待处理订单

🧾 生成单个订单

入库字段：records.code = 专属编号（非 YG 前缀自动补 YG-）· product_ref = 编号 · info = {text: 光语} · image_urls = 图片文件名。若选择了客户账号，将同时建一条 已发货 订单（items[0].name = 编号），生成成功后弹窗展示 订单号 + 防伪码 供复制。

📦 批量生成

逐枚生成 YG-YYMMDD-XXXXXX 唯一码 → records.code 唯一 · product_ref = 产品名称 · info = {text: 光语} · image_urls = 图片，全部入库后列出全部码并可一键复制。适合同一作品的多件成品统一建档。

👥 用户管理

📧 邮件设置

下单 / 发货 / 重置密码 等通知均发往这些邮箱（email-send / account-api 从 settings 表 key=mail 读取收件人）。
保存时「收件邮箱」按行拆分写入 to；发件邮箱/授权码/主机/端口为 SMTP 配置，授权码留空则沿用原值。已存在 settings.mail 则更新，否则新建，不会丢配置。

📖 知识管理

数据表 articles，供前台「学堂」页（knowledge.html）读取：排序 sort 升序 + 新建 id 倒序；可见 visible=false 为「下架」，前台不展示。删除会先进入回收站暂存，可在回收站恢复。
📖 新增文章（标题必填）

📮 信箱管理

勾选要发送的账号（共 0 个）：
调 admin-api op:broadcast：范围=全部时发全部注册用户信箱；范围=指定账号时携带 accounts 数组。勾选邮箱后附带 email=true，结果统计「信箱 x / y · 邮件 z」。

🗂️ 数据库记录管理

★ records 专属：行内 复制/预览验证卡/查看详情（表单编辑 产品名·光语·图片）/删除；records 删除为硬删除。settings 等配置请在各自表单分区维护。
